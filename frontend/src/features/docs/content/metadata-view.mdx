The Metadata view describes the newest metadata file **within the selected snapshot range**. An older range can show an older table structure and settings.

The version header shows the metadata update time and metadata file path. All times on this page are shown in your local timezone.

Below the table name, **Table description (How to add it)** shows the string stored in the `icegraph.description` table property. If the property is absent or empty, the page says no description is recorded. Hover, focus, or click **How to add it** for a Spark SQL example: `ALTER TABLE my.table SET TBLPROPERTIES ('icegraph.description' = 'Customer events')`.

### Snapshot statistics

**At a glance** comes from the summary of the current snapshot recorded in the loaded metadata file. Its commit time can precede the metadata update time.

- **Records in data files** is the snapshot's record count before subtracting row deletes. Delete files are shown alongside it.
- **Total file size (data + deletes)** includes both file types and is shown in GiB. Hover over the size for exact bytes, or expand **Exact bytes** to view and copy the original byte count.
- Missing statistics are shown as **Unavailable**. The page explains when no current snapshot exists or the metadata file does not record it.

### Schema and data organization

The schema panel scrolls independently. Use **Expand schema** to display its full height. Nested structs, list elements, and map keys and values retain their field IDs and show whether they are required, optional, or unknown. Field comments and identifier fields appear when recorded. Identifier fields do not imply enforced uniqueness or automatic upsert behavior.

The schema panel explains that column documentation appears below column names. Hover, focus, or click **How to add column docs** for a Spark SQL example: `ALTER TABLE my.table ALTER COLUMN event_type COMMENT 'Signup, purchase, or cancellation'`.

Click the **Schema**, **Spec**, or **Order** link to open that definition in the Specs panel. Use **Full / Diff** there to inspect changes. The schema section also reports earlier schemas available in this metadata file.

Help on Iceberg-specific terms opens on hover, focus, or click. Press Escape to dismiss it.

### Technical details and JSON

Expand the technical sections for storage paths and identifiers, branches and tags, properties, and delete statistics. JSON-valued properties are formatted and long values can be expanded.

**Advanced: metadata JSON** shows the returned metadata in a scrollable, highlighted block. **Copy metadata JSON** copies exactly the displayed JSON. The backend omits `metadata-log`, `snapshot-log`, `snapshots`, and `statistics` due to size; this export is not the full original metadata file.
