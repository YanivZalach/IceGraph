### 1. Enter the table name

From the Home page, type the fully-qualified name of your Iceberg table (e.g. `database.table_name` ) and press Enter or click Continue. You can also click **Browse catalog** to list Iceberg tables from the Spark catalog. Use the filter field to narrow the list when many tables are available. When the non-Iceberg catalogs are included, the list notes that non-Iceberg tables may also appear.

### 2. Pick a snapshot range

IceGraph shows the table's snapshot history as a single list, newest first. Click a snapshot to start a range, then click a second snapshot to finish it. The two ends are ordered automatically, and the range is inclusive. Clicking once more starts a new range. Click **Latest** at the top to end the range at the newest snapshot, or **Full history** at the bottom to start from the table's first snapshot. A smaller range loads faster and produces a less cluttered graph. Click **Generate Graph** or press Enter to continue. A table with no snapshots yet shows a note instead of the list, and you can still generate its graph.

Below the list, the page shows the table's latest metadata without building a graph: the metadata file, current snapshot statistics, schema, partitioning, sort order, technical details, and metadata JSON. The Schema, Spec, and Order links and the navbar **Specs** button open the Specs panel here as well.

### 3. Wait for the graph

IceGraph prepares the graph in place of the snapshot list, so the table's latest metadata stays visible below it. The loading panel shows which preparation steps are active and how many have completed, including the final graph build. Large ranges with many data files may take a moment. Once ready, you land on the Timeline view. If preparation fails, the panel shows the error and a button to return to the snapshot list with your range kept.

### Switching tables

While viewing a table, on the snapshot selection page or any table view, click the table name in the navbar to change tables. Enter a new table or use **Browse catalog**, then click Continue. IceGraph opens the new table in a separate browser tab so your current page stays loaded. The navbar **Docs** button and the IceGraph logo, which leads to the Home page, also open in a new tab, so your selected range and loaded graph are kept.
