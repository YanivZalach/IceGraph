### Global

- `1`: Go to Timeline view
- `2`: Go to Metadata view
- `3`: Go to FileTree view
- `4`: Go to Graph view

Throughout the app, `j` / `↓` and `k` / `↑` scroll the active panel or list.

### Docs Page

- `k`: Open the documentation search overlay
- `Ctrl` / `n`: Select the next search result
- `Ctrl` / `p`: Select the previous search result
- `Enter`: Open the selected search result
- `Esc`: Close the search overlay

### Timeline View

- `Shift` / `Scroll`: Pan the timeline horizontally
- `r`: Center and zoom to fit the entire timeline
- `h` / `←`: Select the previous snapshot - if none is selected, jumps to the first (oldest)
- `l` / `→`: Select the next snapshot - if none is selected, jumps to the last (newest)
- `j` / `↓`: Scroll the snapshot details panel down
- `k` / `↑`: Scroll the snapshot details panel up
- `f`: Toggle fullscreen for the snapshot details panel (when open)
- `Esc`: Close the snapshot details panel

### Metadata View

- `j` / `↓`: Scroll the page down
- `k` / `↑`: Scroll the page up

### Graph View

- `c`: Center and zoom to fit the entire graph
- `r`: Reset view to initial state
- `i`: Toggle inspect mode (disables keyboard navigation so you can interact freely with the graph)
- `Enter` / `Space`: Jump to the main metadata node
- `h` / `←`: Navigate to the selected node's parent(s)
- `l` / `→`: Navigate to the selected node's child(ren)
- `j` / `↓`: Scroll the node details panel down (when open)
- `k` / `↑`: Scroll the node details panel up (when open)
- `f`: Toggle fullscreen for the details panel (when open)
- `Esc`: Close the node details panel
