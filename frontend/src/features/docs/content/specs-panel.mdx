The **Specs** button in the navbar, on table pages and on the snapshot selection page, opens the Table Specification panel, which shows the full history of your table's structural definitions across three sections:

- **Schema History** - every schema version the table has had, showing each by its schema ID

- **Partition History** - every partition spec version, showing each by its spec ID

- **Order History** - every sort order version, showing each by its order ID

The Metadata view and the latest metadata on the snapshot selection page can open a definition directly from their Schema, Spec, and Order links. The selected definition opens immediately. Use **Clear selection** to return to the history lists without closing the panel.

The currently active version in each section is highlighted with an **ACTIVE** badge. Click any version to expand its full field-level definition.

Schema diff markers appear before each field ID:

- `+` means added
- `-` means removed
- `~` means changed
- `·` marks an unchanged parent containing a nested change

Moved fields appear under both parent paths: `←` marks the old location and `→` marks the new location.
Hovering a marker shows its meaning.

Partition and sort diffs use `+`, `-`, and `~` for added, removed, and changed rows. Removed values are struck through.
