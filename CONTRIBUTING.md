# Contributing to IceGraph

Thank you for contributing to IceGraph.

## Before submitting a contribution

1. Read [ARCHITECTURE_PHILOSOPHY.md](ARCHITECTURE_PHILOSOPHY.md).
2. Open or reference an issue for substantial changes.
3. Sign the [Contributor License Agreement](CLA.md) when the CLA check requests
   it on your pull request.

## Licensing of contributions

The public project is licensed under `AGPL-3.0-only`. By submitting a
contribution, You license it under the project license in effect on the
submission date and under the additional terms of the CLA. The CLA allows the
project steward to offer IceGraph under other licenses, including commercial,
source-available, and proprietary licenses.

Pull requests cannot be merged until every contributor to the pull request has
signed the current CLA.

## Development checks

Follow the setup and validation commands in [README.md](README.md). Keep changes
focused, preserve existing copyright and attribution notices, and include tests
where practical.
