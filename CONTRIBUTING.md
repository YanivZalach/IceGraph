# Contributing to IceGraph

Thank you for contributing.

## Before opening a pull request

1. Read [ARCHITECTURE_PHILOSOPHY.md](ARCHITECTURE_PHILOSOPHY.md).
2. Open or reference an issue for substantial changes.
3. Read the [IceGraph Individual Contributor License Agreement](https://gist.github.com/YanivZalach/dde6f1bf88b42628f64609e5b2d4f860).
4. Keep changes focused. Tests may be used temporarily during development, but test files must be
   removed before submission and must not be included in the contribution. Run the applicable
   format, lint, typecheck, build, and behavioral checks instead.
5. Use the same GitHub account for your commits and CLA acceptance so CLA
   Assistant can identify you.

## Accept the CLA

The CLA lets you keep ownership of your contribution while giving IceGraph
permission to use and license it. After opening a pull request, follow the link
posted by CLA Assistant, sign in with the GitHub account associated with your
contribution, review the agreement, and click **I agree**.

CLA Assistant records your acceptance for the current agreement version and
updates the pull request check. If the agreement changes, CLA Assistant will
ask you to review and accept the new version on a later pull request.

The individual agreement covers only contributions whose copyright you own.
If your employer or another legal entity owns the copyright, contact
[the project maintainer](mailto:yzal2318@gmail.com) before contributing because
the copyright owner must enter into a separate Entity Contributor License
Agreement.

## Third-party material

If any part of your contribution is not your own work, it must be under a
license compatible with `AGPL-3.0-only` (MIT, BSD, and Apache-2.0 are fine;
GPL, LGPL, MPL, SSPL, and proprietary licenses are not), you must keep its
original copyright and license notice, and you must name the source and its
license in the pull request description. Third-party material is not covered
by your CLA grant.
