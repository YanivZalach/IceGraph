# Contributing to IceGraph

Thank you for contributing to IceGraph.

## Before submitting a contribution

1. Read [ARCHITECTURE_PHILOSOPHY.md](ARCHITECTURE_PHILOSOPHY.md).
2. Open or reference an issue for substantial changes.
3. Read the [Contributor License Agreement, version 1.0](CLA.md).
4. Personally check the CLA acceptance box when opening your pull request.

## Licensing of contributions

The public project is licensed under `AGPL-3.0-only`. By submitting a
contribution, You license it under the project license in effect on the
submission date and under the additional terms of the CLA. The CLA allows the
project steward to offer IceGraph under other licenses, including commercial,
source-available, and proprietary licenses.

Pull requests cannot be merged until every contributor has accepted the
current CLA. The pull request author accepts by personally checking the box in
the pull request body. Each additional author or co-author must personally post
the following comment on the pull request:

> I have read and agree to the IceGraph Contributor License Agreement, version
> 1.0, and I confirm that I have authority to submit my contribution.

Maintainers verify acceptance manually before merging. No external signing
service is required. Every pull request requires a new acceptance. If the CLA
changes, the project steward increments its version and effective date and
preserves the prior version. The project steward also updates both acceptance
statements and links them to an immutable Git revision containing the new CLA
version without altering earlier pull request records.

Material proposed in an issue, discussion, email, or another channel is not
accepted for inclusion until its contributor personally accepts the CLA on the
pull request that includes it.

## Development checks

Follow the setup and validation commands in [README.md](README.md). Keep changes
focused, preserve existing copyright and attribution notices, and include tests
where practical.
